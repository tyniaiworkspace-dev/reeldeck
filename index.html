The apps they already use

Tapping opens the real app if it is installed, otherwise the website. No account needed for Dailymotion or YouTube.

Keep a copy — no account, ever

A saved file never asks for an email, never expires and plays with no signal. Three ways to get one:

  • Save a copy. Open any video and tap Save a copy. The phone's share sheet lists any downloader app you have. Pick it and the whole episode downloads.
  • Downloader apps. YTDLnis or Seal — both free, no account, no ads. Paste a link, get the file.
  • Send it over. Tap Share → WhatsApp to the family organiser. They run it through the home ripper and send the file back.

Watching inside ReelDeck also needs no account. The next panel is only for when Dailymotion itself blocks a link.

Throwaway inbox — never your real email

Some sites ask for an address before they play, or before they let a story continue. Make one here instead. It needs no sign-up, it lives on this phone, and it dies by itself. Give the address out, read whatever arrives below, then forget it.

Leave the name blank for a random one. If a site only asks for an address and never sends a code, any address works — you can type one without opening this page.

Which kind of wall is it?

  • Only an address. Type anything — anything@guerrillamailblock.com works and nothing is sent. Skip this page.
  • A code or a link. Make an inbox above, tap Copy + open Dailymotion, paste the address. The mail appears here within ten seconds.
  • A full account. Use the same address to sign up; the confirmation lands here. Write the password down — the address dies after an hour.
  • “Continue with Google”. The only one that stays signed in. Add one shared Google account to each phone once; after that it is one tap and nothing is ever typed again.

Want mail that comes to you instead? Gmail plus: add +anything before the @ (e.g. name+drama@gmail.com) — it still lands in that inbox and tells you who leaked it. DuckDuckGo: the free DuckDuckGo app makes unlimited @duck.com addresses that forward to a real inbox and can be switched off later.

If it still asks for an email

The player inside ReelDeck never needs an account. If the Dailymotion site or app asks anyway, these four checks tell you what is causing it:

  • Incognito. Chrome ⋮ → New Incognito tab, paste the link. If it plays there, the prompt came from saved cookies.
  • Switch data. Turn Wi‑Fi off, or back on. That is a different IP address. If it plays on one, the prompt is address-based.
  • Desktop site. Chrome ⋮ → Desktop site. If it plays, the prompt is the mobile layout.
  • Another copy. Tap “Find the full version”. The same story on another channel often plays.

If all four still ask, stop fighting it — use Save a copy above. A file on the phone has no login screen.

What this runs on

Every piece is free: GitHub Pages for the app, the home machine for the catalogue crawl, Dailymotion's public API for the data, yt-dlp for full copies, a keyless inbox for the email wall. The full list of free services we can wire next — storage, servers, mail, APIs — is in FREE-STACK.md.
